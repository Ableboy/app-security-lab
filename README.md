# wp-security-lab
It is as important as web security, same as WordPress security, because it carries 43% of the entire website build-up. 

# By the end, I can:

1.  Investigate a hacked WordPress site down to the root cause.
2.  Independently verify someone else's cleanup and state exactly what you tested.
3.  Harden a site at three layers: application, server and edge (Cloudflare).
4.  Find and responsibly report vulnerabilities in plugins.
5.  Automate your work with my own tools.
6.  Explain all of it in clear, evidence-based reports.

# Operating principles

1.  Build as I study. Every week ends with something published (GitHub and Medium).
2.  Find, reproduce, fix, document, publish, only in my own lab.
3.  Permission only. Touch only systems you own or have written permission for. Never download real malware; use harmless simulations and published write-ups.
5.  Depth block. 45 minutes daily, and each week at minimum: 1 write-up, 1 code commit, 1 deep-dive note.
